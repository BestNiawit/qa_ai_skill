🚀 ยินดีต้อนรับสู่โลก Automation Testing

คู่มือฉบับน้องใหม่สำหรับติดตั้งเครื่องมือ Automation Testing ตั้งแต่ศูนย์ ครอบคลุมทั้ง Mac และ Windows พร้อม Appium (Mobile) และ Playwright (Web)

macOS 13+ Windows 10/11 Node.js 20+ Appium 2.x Playwright 1.4x Selenium 4.13 Robot Framework 6.1

📖 วิธีใช้คู่มือนี้

อ่านไปทีละข้อแล้วติ๊ก ✅ เมื่อทำเสร็จ ระบบจะจำไว้ในเบราว์เซอร์ของน้อง แม้ปิดหน้าไปก็กลับมาทำต่อได้

🍎 เลือก Tab Macถ้าใช้ MacBook หรือ iMac
🪟 เลือก Tab Windowsถ้าใช้ PC Windows 10/11
📋 คลิก Copyเพื่อคัดลอกคำสั่งไปวางใน Terminal
✅ ติ๊ก Checkboxเพื่อ mark ว่าทำสเต็ปนั้นเสร็จแล้ว
ถ้าติดปัญหา ให้เลื่อนลงไปดูส่วน แก้ปัญหาที่พบบ่อย ด้านล่างสุด

Step 1 ติดตั้ง Node.js + npm

เครื่องมือพื้นฐานสำหรับรัน JavaScript/TypeScript — จำเป็นสำหรับ Playwright และ Appium

ติดตั้งผ่าน Homebrew (แนะนำ)

Homebrew คือ package manager สำหรับ Mac ถ้ายังไม่มี ให้รันคำสั่งนี้ก่อน:

Terminal
# 1) ติดตั้ง Homebrew (ข้ามได้ถ้ามีแล้ว)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Terminal
# 2) ติดตั้ง Node.js (LTS)
brew install node

# 3) ตรวจสอบเวอร์ชัน
node -v
npm -v
แนะนำให้ใช้ nvm (Node Version Manager) เพื่อสลับเวอร์ชัน Node ได้สะดวก — ทีมหลายที่นิยมแบบนี้มากกว่า
ติดตั้ง nvm (ทางเลือก)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# reload shell แล้วรัน
nvm install --lts
nvm use --lts

ติดตั้งผ่าน winget (แนะนำ)

เปิด PowerShell ด้วยสิทธิ์ Administrator แล้วรัน:

PowerShell (Admin)
winget install OpenJS.NodeJS.LTS

# ปิด-เปิด PowerShell ใหม่แล้วตรวจสอบ
node -v
npm -v
หรือดาวน์โหลด installer จาก nodejs.org → เลือก LTS version (.msi)

ทางเลือก: nvm-windows

PowerShell
winget install CoreyButler.NVMforWindows

# ปิด-เปิด PowerShell แล้วรัน
nvm install lts
nvm use lts
ตรวจสอบเวอร์ชัน: ควรได้ Node.js 20.x ขึ้นไป และ npm 10.x ขึ้นไป

Step 2 ติดตั้ง Git

ใช้สำหรับดึงโค้ดจาก GitHub และส่ง pull request

Terminal
brew install git
git --version
PowerShell (Admin)
winget install --id Git.Git -e --source winget
git --version

หลังติดตั้งจะได้โปรแกรม Git Bash มาด้วย — แนะนำให้ใช้ Git Bash รันคำสั่งแบบ unix-like

ตั้งค่าเบื้องต้น (ทำทั้ง Mac และ Windows)

Terminal / Git Bash
git config --global user.name "ชื่อของน้อง"
git config --global user.email "your-email@example.com"
git config --global init.defaultBranch main
git config --global core.autocrlf input   # Mac/Linux
# ถ้า Windows ใช้: git config --global core.autocrlf true

สร้าง SSH Key เพื่อเชื่อมกับ GitHub

Terminal / Git Bash
ssh-keygen -t ed25519 -C "your-email@example.com"
# กด Enter ผ่าน passphrase ได้ (หรือใส่เพื่อความปลอดภัย)

# แสดง public key เพื่อ copy ไปใส่บน GitHub
cat ~/.ssh/id_ed25519.pub
ไปที่ GitHub → Settings → SSH and GPG keys แล้วกด New SSH key วาง public key ลงไป

Step 3 ติดตั้ง Visual Studio Code

Editor ยอดนิยม พร้อม extension ครบสำหรับ automation testing

Terminal
brew install --cask visual-studio-code
PowerShell (Admin)
winget install Microsoft.VisualStudioCode

Extensions ที่แนะนำ (รันใน Terminal หลังติดตั้ง VS Code)

Terminal / PowerShell
# Playwright + JS/TS
code --install-extension ms-playwright.playwright
code --install-extension dbaeumer.vscode-eslint
code --install-extension esbenp.prettier-vscode

# Python
code --install-extension ms-python.python
code --install-extension ms-python.vscode-pylance

# Git / GitHub
code --install-extension eamodio.gitlens
code --install-extension github.vscode-pull-request-github

# คุณภาพชีวิต
code --install-extension streetsidesoftware.code-spell-checker
code --install-extension pkief.material-icon-theme
ถ้าคำสั่ง code ยังใช้ไม่ได้บน Mac → เปิด VS Code → กด ⌘+⇧+P → พิมพ์ "Shell Command: Install 'code' command in PATH"

Step 4 ติดตั้ง Python

จำเป็นสำหรับบาง test framework และ utility scripts

Terminal
brew install python@3.12

# ตรวจสอบ
python3 --version
pip3 --version

สร้าง virtual environment (แนะนำต่อโปรเจกต์)

Terminal
# เข้าไปที่โฟลเดอร์โปรเจกต์ของน้อง
cd /path/to/your-project
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
PowerShell (Admin)
winget install Python.Python.3.12

# ปิด-เปิด PowerShell ใหม่
python --version
pip --version

สร้าง virtual environment

PowerShell
# เข้าไปที่โฟลเดอร์โปรเจกต์ของน้อง
cd C:\path\to\your-project
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install --upgrade pip
ถ้า PowerShell ไม่ยอมให้รัน script ให้เปิด Admin แล้วรัน: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Step 5 ติดตั้ง Java JDK

จำเป็นสำหรับ Appium ฝั่ง Android (และเครื่องมือ Android SDK หลายตัว)

Terminal
brew install --cask temurin@17

# ตรวจสอบ
java -version
javac -version

ตั้งค่า JAVA_HOME

เพิ่มบรรทัดนี้ใน ~/.zshrc (หรือ ~/.bash_profile):

~/.zshrc
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
export PATH="$JAVA_HOME/bin:$PATH"
Terminal
source ~/.zshrc
echo $JAVA_HOME
PowerShell (Admin)
winget install EclipseAdoptium.Temurin.17.JDK

# ตรวจสอบ (ปิด-เปิด PowerShell ใหม่)
java -version
javac -version

ตั้งค่า JAVA_HOME (System Environment Variables)

  • กด Win → พิมพ์ "Environment Variables" → เปิด Edit the system environment variables
  • กด Environment Variables… → ใต้ System variables กด New
  • Variable name: JAVA_HOME
  • Variable value: C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot (path ของ JDK)
  • แก้ไข Path → Add: %JAVA_HOME%\bin
PowerShell (ยืนยัน)
echo $env:JAVA_HOME
java -version

Step 6 ติดตั้ง Android Studio + SDK

จำเป็นสำหรับ Appium ทดสอบแอป Android บน emulator หรือเครื่องจริง

Terminal
brew install --cask android-studio

หลังติดตั้งเปิด Android Studio → More Actions → SDK Manager แล้วติดตั้ง:

  • Android SDK Platform (แนะนำ API 34, 33)
  • Android SDK Build-Tools
  • Android SDK Command-line Tools (latest)
  • Android Emulator
  • Android SDK Platform-Tools (จะได้ adb)

ตั้งค่า ANDROID_HOME

~/.zshrc
export ANDROID_HOME=$HOME/Library/Android/sdk
export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/platform-tools
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin
export PATH=$PATH:$ANDROID_HOME/build-tools/34.0.0
Terminal
source ~/.zshrc
adb --version
sdkmanager --list | head
PowerShell (Admin)
winget install Google.AndroidStudio

เปิด Android Studio แล้วติดตั้ง SDK components เหมือนใน Mac

ตั้งค่า ANDROID_HOME

System Environment Variables → New:

  • Variable name: ANDROID_HOME
  • Variable value: C:\Users\%USERNAME%\AppData\Local\Android\Sdk
  • เพิ่มใน Path ทีละบรรทัด:
    %ANDROID_HOME%\emulator
    %ANDROID_HOME%\platform-tools
    %ANDROID_HOME%\cmdline-tools\latest\bin
    %ANDROID_HOME%\build-tools\34.0.0
PowerShell (ยืนยัน)
adb --version
sdkmanager --list | Select-Object -First 20

ยอมรับ license ทั้งหมด (สำคัญ)

Terminal
yes | sdkmanager --licenses

สร้าง Emulator (AVD) ไว้ทดสอบ

Terminal / PowerShell
sdkmanager "system-images;android-34;google_apis;arm64-v8a"
avdmanager create avd -n Pixel_7_API_34 -k "system-images;android-34;google_apis;arm64-v8a"
emulator -list-avds
emulator -avd Pixel_7_API_34
บน Apple Silicon (M1/M2/M3) ใช้ arm64-v8a; บน Windows/Intel ใช้ x86_64

Mac only Step 7: ติดตั้ง Xcode + iOS Tools

จำเป็นสำหรับทดสอบแอป iOS ด้วย Appium (ข้ามได้ถ้าไม่ได้ทำ iOS)

สำคัญ: Xcode ใช้พื้นที่ดิสก์เกือบ 40 GB และต้องการ macOS เวอร์ชันล่าสุด — ติดตั้งเฉพาะคนที่ทำ iOS automation เท่านั้น

1) Xcode จาก App Store

เปิด App Store → ค้น "Xcode" → กด Install (ใช้เวลานาน ดาวน์โหลด ~15 GB)

2) ยอมรับ license + ติดตั้ง Command Line Tools

Terminal
sudo xcode-select --install
sudo xcodebuild -license accept
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer

3) ติดตั้ง iOS tools ที่ Appium ต้องใช้

Terminal
# สำหรับสื่อสารกับ iPhone จริง
brew install libimobiledevice
brew install ios-deploy

# Carthage (ใช้ build WebDriverAgent บางเคส)
brew install carthage

# ตรวจสอบ
xcodebuild -version
idevice_id -l
ios-deploy --version
ถ้าจะทดสอบบน iPhone เครื่องจริง: ต้องมี Apple Developer account (ฟรีหรือ paid) และ trust device ใน Settings → General → Device Management

4) เปิด Simulator

Terminal
open -a Simulator
xcrun simctl list devices available | head -20

Step 8 ติดตั้ง Appium 2.x

Mobile automation server ที่ทดสอบได้ทั้ง Android และ iOS

1) ติดตั้ง Appium server (ใช้ npm — เหมือนกันทั้ง Mac/Windows)

Terminal / PowerShell
npm install -g appium
appium --version    # ควรเป็น 2.x ขึ้นไป

2) ติดตั้ง Drivers

Terminal / PowerShell
# Android driver
appium driver install uiautomator2

# iOS driver (Mac only)
appium driver install xcuitest

# ดู drivers ทั้งหมด
appium driver list --installed

3) ติดตั้ง Appium Doctor เพื่อ validate environment

Terminal / PowerShell
npm install -g appium-doctor

# ตรวจ Android side
appium-doctor --android

# ตรวจ iOS side (Mac only)
appium-doctor --ios
ให้รัน appium-doctor จนกว่าจะ ✅ ผ่านทุก check ก่อนไปขั้นต่อไป

4) ติดตั้ง Appium Inspector (UI tool สำหรับเลือก element)

Terminal
brew install --cask appium-inspector

ดาวน์โหลดจาก github.com/appium/appium-inspector/releases → เลือกไฟล์ .exe สำหรับ Windows

5) ทดสอบรัน Appium server

Terminal / PowerShell
appium

# ถ้าสำเร็จจะเห็น:
# [Appium] Welcome to Appium v2.x.x
# [Appium] Appium REST http interface listener started on http://0.0.0.0:4723

Step 9 ติดตั้ง Playwright

End-to-end web testing framework ที่รองรับ Chromium, Firefox, WebKit ในคำสั่งเดียว

1) สร้างโปรเจกต์ใหม่ / ติดตั้งในโปรเจกต์ที่มีอยู่

Terminal / PowerShell
# เข้าไปที่โฟลเดอร์โปรเจกต์ของน้อง (หรือสร้างโฟลเดอร์ใหม่)
cd /path/to/your-project          # Mac/Linux
# cd C:\path\to\your-project      # Windows

# สร้างโปรเจกต์ใหม่ (จะถามให้เลือก TS/JS, ภาษา ฯลฯ)
npm init playwright@latest
Playwright installer จะติดตั้ง browsers (Chromium, Firefox, WebKit) อัตโนมัติประมาณ 1 GB

2) ถ้ามีโปรเจกต์อยู่แล้ว ใช้คำสั่งนี้

Terminal / PowerShell
npm install -D @playwright/test
npx playwright install            # ดาวน์โหลดทุก browser
npx playwright install --with-deps # Linux: ติดตั้ง deps ด้วย

3) รัน test ตัวอย่าง

Terminal / PowerShell
npx playwright test                # รันทุก test
npx playwright test --ui           # เปิด UI mode (แนะนำสำหรับ dev)
npx playwright show-report         # ดู HTML report

4) ติดตั้ง Playwright VS Code Extension

ถ้ายังไม่ได้ติดตั้งตอนขั้น VS Code:

Terminal / PowerShell
code --install-extension ms-playwright.playwright

เปิด VS Code → Testing panel (ด้านซ้าย) → กด Record / Run test ได้เลย

5) Codegen — สร้าง test แบบ interactive

Terminal / PowerShell
npx playwright codegen https://example.com
Codegen จะเปิดเบราว์เซอร์ให้น้อง record actions แล้ว generate code เป็น TypeScript/Python/Java ให้เอาไปปรับต่อได้

Step 10 ติดตั้ง Selenium WebDriver

Web automation framework แบบ classic ที่รองรับหลายภาษา (Python, Java, JS) — เหมาะกับ legacy project และใช้ร่วมกับ Robot Framework ได้

Selenium 4.x มาพร้อม Selenium Manager ที่ดาวน์โหลด browser driver (chromedriver/geckodriver) ให้อัตโนมัติ — ไม่ต้องตั้งค่า driver เองเหมือนเมื่อก่อนแล้ว

1) ติดตั้ง Selenium สำหรับ Python (แนะนำสำหรับ QA)

Terminal / PowerShell
# activate venv ของโปรเจกต์ก่อน (ดู Step 4)
pip install selenium
pip install webdriver-manager    # (ทางเลือก) จัดการ driver อัตโนมัติ

# ตรวจสอบ
pip show selenium | grep Version

2) ทางเลือก: ติดตั้ง Selenium สำหรับ Node.js

Terminal / PowerShell
# ในโฟลเดอร์โปรเจกต์
npm install -D selenium-webdriver
npm install -D @types/selenium-webdriver   # ถ้าใช้ TypeScript

3) ติดตั้ง Browsers ที่ใช้ทดสอบ

Terminal
brew install --cask google-chrome
brew install --cask firefox
# Safari มีมาให้แล้วบน Mac — เปิด Develop → Allow Remote Automation
PowerShell (Admin)
winget install Google.Chrome
winget install Mozilla.Firefox
# Edge มีมาให้แล้วบน Windows

4) ทดสอบ Selenium ด้วยสคริปต์สั้น ๆ (Python)

smoke_selenium.py
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("https://www.google.com")
print(driver.title)
driver.quit()
Terminal / PowerShell
python smoke_selenium.py    # ควรเปิด Chrome แล้ว print "Google"
ถ้า Selenium Manager ดาวน์โหลด driver ไม่สำเร็จ ให้ตรวจว่าเวอร์ชัน Chrome/Firefox ตรงกับเวอร์ชัน browser ที่ติดตั้งไว้ หรือใช้ webdriver-manager แทน

Step 11 ติดตั้ง Robot Framework

Keyword-driven test framework ภาษา Python — เขียน test case แบบตารางอ่านง่าย เหมาะกับทีม QA ที่ไม่ถนัด code เยอะ

Robot Framework ต้องการ Python 3.8+ (ได้จาก Step 4) และใช้ Selenium เป็น backend สำหรับ web testing (ได้จาก Step 10)
ทีม Ayodia มี Starter Kit ให้แล้ว — clone มาใช้เป็น baseline ได้เลย ไม่ต้องสร้างโครงเอง:
git clone https://gitlab.ayodiacompany.com/ayodia-tester-teams/automation-starter-kit.git

1) Clone Starter Kit (แนะนำ)

Terminal / PowerShell
git clone https://gitlab.ayodiacompany.com/ayodia-tester-teams/automation-starter-kit.git
cd automation-starter-kit

# สร้าง venv เฉพาะโปรเจกต์
python3 -m venv .venv
source .venv/bin/activate       # Mac/Linux
# .\.venv\Scripts\Activate.ps1 # Windows

pip install --upgrade pip
pip install -r requirements.txt

2) สิ่งที่ requirements.txt จะติดตั้ง

requirements.txt (starter-kit)
robotframework>=6.1,<7
robotframework-seleniumlibrary==6.1.2
robotframework-debuglibrary==2.3.0
selenium==4.13.0
urllib3<2
typing_extensions>=4.10.0
PyYAML==6.0.1
fpdf2==2.7.9

# Quality / dev tooling
robotframework-pabot==2.16.0        # parallel execution
robotcode[all]==0.99.0              # LSP / VS Code support
robotframework-robocop==3.2.1       # linter
robotframework-tidy==4.14.0         # formatter
pre-commit==4.0.1
yamllint==1.35.1
Starter kit ใช้ Robot Framework 6.x (ไม่ใช่ 7.x) เพื่อให้ compatible กับ libraries/tools ที่ทีมใช้อยู่ — อย่าอัปเกรดเป็น 7.x เองโดยไม่ปรึกษาทีม

3) ติดตั้งโดยไม่ใช้ Starter Kit (กรณีสร้างโปรเจกต์เอง)

Terminal / PowerShell
pip install "robotframework>=6.1,<7"
pip install robotframework-seleniumlibrary==6.1.2
pip install selenium==4.13.0 PyYAML==6.0.1

# ตรวจสอบ
robot --version         # ควรเห็น Robot Framework 6.x

4) ติดตั้ง VS Code Extension

Terminal / PowerShell
code --install-extension d-biehl.robotcode          # LSP หลัก (ตรงกับ robotcode ใน requirements)
code --install-extension robocorp.robotframework-lsp # ทางเลือก

5) รัน test จาก Starter Kit

Terminal / PowerShell
# รัน test ทั้งหมดในโฟลเดอร์ testcases/
robot testcases/

# รันเฉพาะไฟล์เดียว
robot testcases/task_magement/TC_M_0002.robot

# เลือก environment (dev/at/prod/ci)
robot --variablefile config/environments/dev.yaml testcases/

# รันแบบ parallel ด้วย pabot
pabot --processes 4 testcases/
หลังรันจะได้ไฟล์ report.html, log.html, output.xml — เปิด report.html เพื่อดูสรุป, log.html สำหรับ step-by-step debug

6) โครงสร้างโปรเจกต์ (จาก Starter Kit)

โฟลเดอร์

├── .github/                    # GitHub workflows

├── requirements.txt

🛠 แก้ปัญหาที่พบบ่อย

1) command not found หลังติดตั้งเสร็จ

สาเหตุ: Terminal ยังจำ PATH เวอร์ชันเก่าอยู่

แก้: ปิด Terminal / PowerShell แล้วเปิดใหม่ — หรือรัน source ~/.zshrc (Mac) / เปิด PowerShell ใหม่ (Windows)

2) appium-doctor ฟ้อง ANDROID_HOME ไม่พบ

ตรวจว่า environment variable ตั้งถูกต้อง และ Terminal โหลดค่าใหม่แล้ว:

Debug
echo $ANDROID_HOME      # ควรมี path ไม่ใช่ว่าง
ls $ANDROID_HOME        # ควรเห็นโฟลเดอร์ platform-tools, emulator, ...

3) Homebrew ติดตั้งไม่ได้บน Apple Silicon

หลังติดตั้ง brew บน M1/M2/M3 ต้องเพิ่ม path ใน ~/.zshrc:

~/.zshrc
eval "$(/opt/homebrew/bin/brew shellenv)"

4) Windows: winget ไม่รู้จัก

อัปเดต Windows 10 เป็น version 1809+ หรือติดตั้ง App Installer จาก Microsoft Store

5) Appium ฟ้อง xcrun: error บน Mac

Terminal
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
sudo xcodebuild -license accept

6) Playwright download browsers ช้า / ติดไฟร์วอลล์

Terminal / PowerShell
# ใช้ mirror จีน/SEA ถ้าเครือข่ายช้า
# Mac/Linux
PLAYWRIGHT_DOWNLOAD_HOST=https://playwright.azureedge.net npx playwright install

# Windows PowerShell
$env:PLAYWRIGHT_DOWNLOAD_HOST="https://playwright.azureedge.net"; npx playwright install

7) Android Emulator ช้า / ไม่เปิด

  • Mac (Apple Silicon): ใช้ system image arm64-v8a เท่านั้น
  • Windows: เปิด Hyper-V หรือ WHPX ใน Windows Features
  • ปิด VirtualBox / อย่ารัน emulator หลายตัวพร้อมกัน

8) ต้องการ reset ทุก checkbox ในหน้านี้
